请实际操作（能开浏览器就用浏览器看；不能就用 curl 读接口与首页 HTML，并如实说明）：
1. 「开始」页：GET /api/projects、GET /api/doctor；用 POST /api/projects/detect 和 POST /api/projects 接入一个你自己在临时目录 git init 并提交两次、带一个 worktree 分支的小仓库（项目名自取）；再 POST /api/sync?project=<名> 先 dry_run 再真登记。判断：一个新手能不能不碰终端就完成「检查环境 → 接入项目 → 登记现有分支」？
