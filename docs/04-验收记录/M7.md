## 期间发现并修复的问题
- **一个 `heliu sessions --json` 进程挂了 2 天多、吃满一个核**：调用方不读输出也不关管道时，输出缓冲会一直重试。修复为下游 15 秒没有读取就放弃剩余输出并退出，写 0 字节也不再空转；加了回归测试（`tests/flush.test.ts`）。
- **类名串扰两处**：星图 `.link` 规则把「重新检查」等文字链接压到 8% 透明度；`.next` 规则把「下一版」徽章撑成大块。均已限定作用范围。
- **hook 计时测试偶发失败**：hook 代码未改；机器负载高（WindowServer 95%、其他应用 GPU 50%）时同一 hook 从 0.1 秒变成 0.3 秒。未放宽 300ms 上限，已写入 README 已知限制。
