# M5 任务卡：接入磁吸背夹 + plugin 打包 + 文档

## 目标
让用户明天打开桌面应用就能用：任何会话都有 `/heliu` 与 MCP 工具；看板一条命令打开；磁吸背夹的台账已从现状生成。

## 内容
1. **磁吸背夹初始台账**：`heliu sync --project 磁吸背夹` 生成草稿卡（约 40 条独立/进集成分支 → 功能卡；标题取会话标题）；里程碑：`v1.1-收口`（= 现有集成分支 `merge-features-refactor-143693` 并回 main，预约所有已进集成分支）、`v1.2`（独立未合并中仍活跃的）、`以后`（老分支）。生成后输出一张中文清单给用户确认，**不自动决定哪些分支废弃**。
2. **台账落点决策**（询问用户，默认 A）：A 放进文档仓 `.heliu/` 并作为一次独立提交；B 留在 `~/Library/Application Support/heliu/projects/磁吸背夹/ledger/`。
3. **plugin 打包**：`.claude-plugin/plugin.json`、根 `.mcp.json`、`hooks/hooks.json`、`skills/heliu/SKILL.md`、`bin/heliu`、`bin/heliu-hook`；本地 marketplace `marketplace/`，安装脚本 `scripts/install.sh`（`bun install`、注册 user 级 MCP `claude mcp add -s user heliu -- bun <abs>/bin/heliu mcp`、`claude plugin marketplace add` + `install`）。用桌面应用内置 CLI（2.1.308）验证 `--plugin-dir` 可加载。
4. **README**：中文，首屏 3 句话 + 一张看板截图 + 三条口语化用法 + 安装三步；附 docs 索引。
5. **其他项目接入**：`heliu project add <path>` 向导（自动猜主线/集成分支），对 iDock 的 patent-figure-kit 试一次。
6. **ChatGPT 终验**：以普通用户视角走产品定义第 9 节 6 条口径，≤3 轮，记录 `docs/04-验收记录/M5.md`。
7. **提交并询问推送**（本仓库无远端：建议 `gh repo create janauto/heliu --private`，等用户点头再推）。

## 验收
- 新开一个磁吸背夹会话，SessionStart 注入出现「【合流】你在 文档仓/…」；说"做个 X"后 `heliu 待办 下一版` 出现 X。
- `heliu board` 打开即见磁吸背夹三仓库健康条与版本列。
- `claude plugin install heliu@local` 成功，`/heliu` 可用。
