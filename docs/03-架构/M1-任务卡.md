# M1 任务卡：对账单只读内核 + CLI

## 目标
在不改动任何被管理仓库的前提下，把「分支 × worktree × 桌面会话」联成一张对账单，CLI 中文输出 + `--json`。

## 仓库与栈
- 本仓库根目录 = `heliu` 包根。Bun 1.3 + TypeScript（strict）。`node_modules` 用 `node_modules.nosync` 实体目录 + 符号链接（iCloud 不同步 `.nosync`），两者都进 `.gitignore`。
- 依赖最少：`commander`、`yaml`、`zod`（校验 project.yaml 与会话 JSON）、`cli-table3` 或自写对齐（中文全角宽度要正确，可用 `string-width`）。测试用 `bun test`。

## 目录
```
src/
  types.ts
  core/project.ts      # 读 ~/Library/Application Support/heliu/projects/<name>/project.yaml；<repo>/.heliu/project.yaml 优先
  core/git.ts          # runGit(repo, args, {timeoutMs=8000, optionalLocks=false}) → {ok, stdout, timedOut}
  core/branches.ts     # for-each-ref；ahead/behind vs main & integration；is-ancestor；mergedState 三档；可选 merge-tree 预检
  core/worktrees.ts    # worktree list --porcelain；目录名≠分支名；孤儿 .git/worktrees/*；index.lock；dirty(超时→unknown)
  core/sessions.ts     # 解析桌面会话 JSON 与 git-worktrees.json（只读、zod 宽松、缺字段容错）
  core/labels.ts       # 随机分支名 → 可读标签：会话标题 > 首提交主题 > 改动最多的一级目录 + 最后日期
  core/reconcile.ts    # join → ReconcileReport {health, repos[{branches[FeatureView]}], hygiene}
  cli/index.ts         # heliu status|branches|sessions|hygiene|doctor|project (add|list) ; --project ; --json ; --precheck
tests/                 # 用临时 git 仓库造 fixture（多分支、worktree、落后、已合并、孤儿）
```

## 数据源（已核实）
- 桌面会话：`~/Library/Application Support/Claude/claude-code-sessions/<账号>/<组织>/local_*.json`，字段：`sessionId, cliSessionId, title, cwd, originCwd, worktreeName, worktreePath, branch, sourceBranch, writtenBranches, prs[{prNumber,repo,url,branch,state}], postTurnSummary{status_category,status_detail,needs_action}, isArchived, createdAt(ms), lastActivityAt(ms), completedTurns, spawnedFrom{sessionId,title}, model`。与仓库的归属用 `originCwd`/`cwd` 的真实路径（realpath）匹配 project.yaml 里的 repo path 或其 `.claude/worktrees/*`。
- `~/Library/Application Support/Claude/git-worktrees.json`：`worktrees{<name>:{name,path,branch,sourceBranch,baseRepo,leasedBy,createdAt,uncleanSince}}`。
- 运行中会话：`~/.claude/sessions/<pid>.json`（hostSessionId、name、status idle/busy）。

## git 纪律（硬约束）
- 允许：`for-each-ref`、`rev-list --count`、`merge-base --is-ancestor`、`merge-tree --write-tree --name-only`、`worktree list --porcelain`、`log -1 --format`、`symbolic-ref`、`rev-parse`、`diff --stat A...B`、`status --porcelain -uno`（仅在 `GIT_OPTIONAL_LOCKS=0` + 超时下）。
- 禁止：`checkout`、`merge`、`fetch`、`pull`、`push`、`stash`、`worktree add/remove/prune`、`branch -d`、`gc`。代码里用白名单拦截。
- 每个 repo 并发 ≤4 个 git 进程；iCloud 仓库 dirty 检查默认跳过（`--dirty` 才查）。

## 输出
- `heliu status --project 磁吸背夹`：顶部健康条（主线 vs 远端 ahead/behind；集成分支未并回主线天数；从未推送分支数；worktree 脏/未知/干净计数），每仓库一张表：标签 | 分支 | worktree | 会话（标题·状态） | 领先/落后主线 | 领先/落后集成 | 合并状态 | 最后提交。
- `heliu hygiene`：目录名≠分支名、孤儿条目、index.lock、已合并但目录仍在、无提交的 worktree、主目录脏项计数。
- `heliu sessions`：本项目会话列表（含 blocked/needs_action）。
- `heliu doctor`：git ≥2.38、bun、数据目录可读、每仓库可达、iCloud 警告。
- 所有命令支持 `--json`（稳定 schema，供 MCP/看板复用）。

1. `bun test` 全绿。
2. `heliu status --project 磁吸背夹` 60s 内完成、不挂起；文档仓数字对得上：本地分支 75、worktree 54、未合并进 main 51、其中 13 条已被集成分支包含。
