# M7 任务卡：星图（宇宙星河风格的分支关系图 + 拖拽连线）

## 用户原话
1. 视觉像宇宙、星河、流变；能在多个分支间快速找到最新的分支，以及其他单独分支的情况；快速展开，科技感、动态、丝滑。可以从纵横之间得知项目每个节点的关系。
2. 交互尽可能多用拖拉拽，类似拼图和线段连接：在线条里看到项目之间的关联；也能在交互中快速把某个子功能与一个节点合并。

## 范围
新增一个页签「星图」，其他页签风格不变（"清晰 > 花哨"已过 Codex 新手验收）。星图画布常驻深色宇宙风；页面外框跟随系统主题。

## 纵横布局（确定性，不用力导向）
- **横轴 = 时间**：每条分支的最后提交时间，越靠右越新；用平方根刻度，最近几天展得开，几个月前的压在左边。刻度：今天 / 3 天 / 1 周 / 1 月 / 更早。
- **纵轴 = 仓库泳道**：每个仓库一条带；带内有两条"星河主流"——主线、集成分支；功能分支是星点，按状态分层排在带内。
- **右侧 = 版本星座**：每个里程碑一颗"行星"，外加「未预约」。功能卡与它预约的版本之间画细连线（星座线）。
- **流线**：功能分支到它的目标主流画一条曲线。已进集成 = 亮实线汇入；独立未合并 = 流动虚线；有冲突 = 红；落后 = 暗黄并标 ↓N；等你回答 = 紫色脉冲。集成分支到主线画"未并回"长弧，标领先数和天数。
- **最新**：最后提交最新的 3 条分支加光晕呼吸和「最新」标记；搜索框高亮匹配。
- 同一张功能卡绑定了多个仓库的分支（如固件 + App）时，卡片星点与各分支之间连线，跨泳道看得到关联。

## 拖拽（Pointer Events，鼠标和触屏都能用；拖动时从起点牵出一条发光线段，可放的目标会亮起）
| 拖什么 | 放到哪 | 发生什么（只写台账 / 合并单） |
|---|---|---|
| 分支星点（已有卡） | 版本行星 | 改预约到该版本 |
| 分支星点（还没卡） | 版本行星 | 以分支标签为标题新建功能卡，绑定该分支，预约到该版本 |
| 分支星点 | 尚未关联分支的功能卡星点 | 把分支绑定到这张卡 |
| 任意功能卡 / 分支 | 「未预约」 | 取消预约 |
| 功能卡 / 分支 | 集成主流（「合流点」） | 排进它所在版本的合并单并把决定设为「并入」，立刻显示这一项的试合结果（冲突文件数）和执行命令 |

**边界（明确）**：拖到合流点**不执行 git 合并**。真正的合并仍在终端 `heliu 合并 <版本>`，看到摘要后输入 yes 才开始，可回滚（ADR-4 不变）。如果用户要求拖拽直接执行合并，单独再改安全约定。

## 新接口
- `POST /api/features` 支持 `bind: {repo, branch}`：从分支建卡（已有卡的分支拒绝并报卡号）。
- `POST /api/features/:id/bind` `{repo, branch}`：绑定分支。
- `POST /api/release/decision` `{feature, decision, milestone?}`：必要时先预约 → 刷新合并单（保留已改的决定）→ 设决定；返回该项的试合结果与终端命令。

## 动效与性能
- 星空背景：canvas 粒子缓慢漂移闪烁；主流：渐变描边 + 流动 dash 动画；星点：径向渐变 + 光晕；进入时星点依次展开。
- `prefers-reduced-motion` 时全部静止。数据只来自 `/api/status` + `/api/features`（20 秒缓存），绝不按帧或按节点请求。
- 手写 SVG + CSS，不引入图形库。375px 宽可横向滚动查看，拖拽在触屏同样可用。

## 验收
1. 新接口测试：从分支建卡、重复建卡拒绝、绑定、设并入（含自动预约与刷新合并单）、被管理仓库零写入。
2. 内置浏览器实测：磁吸背夹 119 条分支流畅显示；最新分支一眼可见；拖分支到版本行星生效；拖到合流点出现试合结果；375px 可用。
3. Codex 以新手视角与 M6 合并验收。
