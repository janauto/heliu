# M8 任务卡：分类收纳 · 整机结构 · 拖拽合并闭环

## 用户原话
1. 最终合并可以用拖拉拽的形式，自动把需要合并的版本号以 Prompt 形式复制到剪贴板；合并完分支之后，快速把这一点同步到这个工具上。
2. 节点分支太多，反而太乱、不够整洁。要做分类，比如 bug 修复、功能点迭代，以及整机功能可视化的结构化呈现。考虑怎么收纳这些信息点，让人很快获取信息核心并做出决策。

## 一、拖拽合并闭环（不改 ADR-4）
- **拖版本行星到合流点 = 合并这一版**：刷新该版合并单，自动把一段中文 Prompt 复制到剪贴板。拖功能星点到合流点（排进合并单「并入」）后，同样复制这段 Prompt。
- Prompt 给 Claude 会话用，内容：① 运行 `heliu 合并 <版本> --预演` 并用中文讲清新增合入 / 已在集成 / 顺延 / 冲突；② **不要替我执行合并**，我会在终端自己运行 `heliu 合并 <版本>`，看摘要输入 yes 才开始，可回滚；③ 合并完成后运行 `heliu 同步合并结果` 并汇报。**Prompt 里绝不出现 `--yes`。**
- **合并后同步**：新命令 `heliu 同步合并结果 [--dry-run]`、MCP `heliu_after_merge`（默认只预览）、看板按钮「刚合并完？同步一下」。对每张还没合入的卡：它的分支（有独有提交的那些）全部已被集成分支 / 主线包含 → 建议改成「已合入」/「已进主线」。看板与 MCP 先列出、勾选确认后才写；CLI 不带 `--dry-run` 直接写（用户主动运行即为确认）。只写台账状态，不碰仓库。
- 用 `heliu 合并` 执行的合并本来就会更新台账；这个同步主要补「在别处手动合并」的情况。

## 二、分类：类型 × 模块（推测 + 用户说了算）
- **类型**：修复 / 功能 / 调研 / 文档 / 工程 / 其他。按卡片标题、会话标题、分支名、首条提交的关键词推测（fix/bug/修复/错误… → 修复；调研/评估/可行性… → 调研；合并/同步/重构/测试… → 工程；文档/说明书/PRD/视频/归档… → 文档；其余 → 功能）。
- **模块**（整机的组成部分）：内置一套通用词典（语音与对话、界面与交互、通话、固件与连接、手机 App、平台与接口、产品与资料、其他），项目可在台账目录放 `modules.yaml` 覆盖（名字 + 关键词）。
- **存储**：卡片 frontmatter 新增可选字段 `type`、`module`。不写时界面显示「推测」；用户在详情面板 / 结构页 / 星图拖拽 / CLI 改过才写入。没有卡的分支只按推测分组显示，不落盘。

## 三、收纳：星图按类型折叠 + 新「结构」页
- **星图**：每条仓库泳道按类型分成几行；默认每行收成一个"星团"（显示数量、状态分布条、最新时间），点一下展开成星点，「全部展开 / 全部收起」一键切换。颜色仍表示状态（等你 / 冲突 / 可合 / 落后），**形状表示类型**（修复 ◆、功能 ●、调研 ▲、文档 ■、工程 ⬢）。
- **结构页（整机功能）**：一页看完——顶部「现在该决定的」（可合并 / 等你 / 冲突 / 落后 / 已合入待确认，点了跳到对应处理）；中间「模块 × 类型」矩阵；下方每个模块一张卡（进度、各状态数、最需要决定的三项，可展开全部并改类型 / 模块）。
- 不另做第二个看板：结构页只是汇总 + 下钻。

## 新接口
- `PATCH /api/features/:id` 支持 `type`、`module`；`/api/features` 的卡片带 `type/typeSource/module/moduleSource`，并返回模块定义。
- `POST /api/release/prompt {milestone}`：刷新合并单，返回 Prompt、终端命令、同步命令、计数。
- `GET /api/merged`（建议列表，基于最新对账）、`POST /api/merged {ids}`（确认写入）。
- CLI：`heliu feature set <卡号> --type 修复 --module 语音与对话`；`heliu 同步合并结果`。MCP：`heliu_feature_set_status` 增加 type/module；新增 `heliu_after_merge`。

## 验收
1. 测试：分类推测、frontmatter 往返（含手写 type 不被覆盖）、合并后同步（建议 / 写入 / 不降级 / 尚无提交不算）、Prompt 不含 --yes、星团布局。
2. 浏览器：磁吸背夹星图默认整洁（每仓库几行星团）；展开 / 收起顺滑；拖版本行星到合流点后剪贴板里有 Prompt；结构页一屏看清各模块；深色、375px。
3. Codex 新手视角验收。
